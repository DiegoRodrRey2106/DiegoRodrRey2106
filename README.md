## Selected project

### Electric Vehicle Motor Energy Management System

My IPN-ESCOM degree project integrates an **ESP32** for sensor acquisition and PWM motor control with a **Raspberry Pi 5** for control logic, monitoring, and the user interface. The system measures voltage, current, temperature, and speed, and sends data over UART. The team validated the prototype through Proteus simulations, breadboard tests, and an assembled PCB.

**Technologies:** C/C++, Python, Tkinter, ESP32, Raspberry Pi 5, UART, PWM, Proteus.
